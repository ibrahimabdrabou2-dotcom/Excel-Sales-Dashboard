# Sales Dashboard using Excel

## Project Overview
This project is an interactive Sales Dashboard built using Microsoft Excel to analyze sales performance and provide business insights.

## Tools Used
- Microsoft Excel
- Data modeling
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

## Dashboard Features
- Total Sales
- Total Profit
- Sales by Category
- Sales by Region
- Monthly Sales Trend
- Interactive Filters
